# BodyLens

App personal de salud (peso y composición, actividad, sueño, corazón, comidas, ciclo, ánimo) que se despliega
con Docker en un servidor propio y se actualiza sola cada 15 minutos con los datos de Withings y Apple Salud
(Health Auto Export).
